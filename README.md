# HTML & CSS Mastery: Foundational Frontend Development

## Overview
This repository documents my comprehensive study and hands-on application of **HTML5** and **CSS3**, building a strong foundation in semantic structure, responsive design, and dynamic UI development. Through project-based learning, I explored core web technologies and modern styling techniques critical for scalable, accessible, and performant frontend systems.

---

## Topics Covered

### HTML
- Semantic elements: `header`, `section`, `article`, `nav`, `footer`
- Lists, forms, tables, and embedded media (images, audio, video)
- Hyperlink structures, favicon usage, button behaviors
- Document flow, nesting, and content hierarchy
- Form controls and input validation

### CSS
- Selectors, combinators, and specificity
- Box model, positioning (`static`, `relative`, `absolute`, `fixed`, `sticky`)
- Flexbox and Grid for responsive layouts
- Styling buttons, cards, navbars, dropdowns, and modals
- Transitions, keyframe animations, transform effects
- Pseudo-classes and pseudo-elements
- Custom fonts, variables, and theming strategies

---

## Projects & Components Built

- **Multi-section landing page** using Flexbox and Grid
- **Fully responsive layout** with media queries and fluid units
- **Interactive dropdown menu** with CSS transitions
- **Table with styled headers and hover states**
- **Navigation bar** with sticky positioning and hover effects
- **Modal and image gallery** with animation
- **Custom buttons and form UI**

All components were built **from scratch without frameworks**, focusing on clean, maintainable, and reusable code.

---

## What I Learned
- How to construct accessible, semantically correct HTML documents
- How to build responsive, scalable layouts from the ground up
- How to create animated, interactive UI components with pure CSS
- How to think like a designer—visual hierarchy, spacing, and color theory basics
- How to debug layout issues and understand rendering behavior across browsers
